1. Live Diff & Staging Workbench — PlaySync Studio

Deep real-time parameter tracking across Transforms, physics colliders, audio, lights, cameras, and custom MonoBehaviours, documented at under 0.1 ms frame impact.

  • Side-by-side diff tree — WAS (Edit Mode) vs NOW (Play Mode) values.
  • Granular commits — commit individual fields, single objects, or all safe rows.
  • Search & filter — by category: Transforms, Scripts, Components, Prefabs.

2. Quick Restore Window — automatic exit stager

A lightweight popup that triggers automatically the moment you exit Play Mode.

  • Smart Conflict Guard — flags properties that were also modified in Edit Mode with amber warnings.
  • 1-click safe restore — applies non-conflicting properties instantly.
  • 100% native Undo — revert any restore operation with Ctrl+Z / Cmd+Z.

3. Direct Unity Inspector integration

  • Embedded status banner — selecting a modified GameObject displays an active banner at the top of the standard Inspector.
  • Quick Apply Now — commit an individual GameObject's changes without opening any window.
  • SceneView floating HUD — an optional live change counter during gameplay sessions.
  • Right-click context actions — right-click any component header to copy C# patches.

4. Game Balance Preset Vault

Save entire balance configurations as native ScriptableObject assets (.asset files).

  • Instant A/B testing — swap player speeds, weapon spreads, or enemy stats.
  • Multi-scene support — apply saved presets across multiple game levels.
  • Version-control ready — presets serialize cleanly into Git with zero binary bloat.

5. 25-Session Flight Recorder — time machine

An automatic local time machine that stores your previous 25 play sessions.

  • Background JSON logging — session changes are logged automatically in Library/PlaySyncHistory/.
  • Time-machine rewind — revisit any previous run, inspect timestamps, and restore its tweaks.
  • Zero repo pollution — history stays local to your machine and never enters your Git repository.

6. Zero-Click Auto-Save Rule Matrix

Define automated persistence rules by component type, GameObject tag, or attribute.

  • Component type rules — always auto-persist Lights, Cameras, or Audio Managers.
  • Tag rules — auto-persist all GameObjects with the "Player" or "LevelDesign" tag.
  • Code attribute — decorate custom scripts with [AutoSavePlayMode]; see the Scripting API page.

7. C# Initialization Patch Generator

Found in the Studio's C# Patch Gen tab. Converts runtime tweaks directly into clean, formatted C# assignment code blocks.

  • Supports Vector3, Quaternion.Euler, Color, AnimationCurve, and primitives.
  • 1-click clipboard copy — suited to hardcoding procedural spawn configurations.

8. Team-Ready HTML Change Reports

Found in the Studio's HTML Report tab. Generates standalone, dark-themed HTML reports in under one second.

  • Category breakdown statistics and side-by-side WAS vs NOW tables.
  • Zero dependencies — a self-contained file, shareable over Slack, Jira, pull requests, and email.
