Quick Start

From import to your first committed change in about five minutes, using the interactive sandbox demo scene that ships with the package.

Step 1 — Open the interactive demo scene

  1. Open Unity and go to Tools > ByteLura > PlaySync > Welcome & Hub.
  2. In the Welcome Hub, click Create Interactive Demo Scene.
  3. Unity generates a clean sandbox scene with interactive test objects:
    • Modify Me (Cube) — Transform, BoxCollider, and MeshRenderer.
    • Modify Me (Sphere) — physics bouncing material, Transform, SphereCollider.
    • Sample Character — a custom MonoBehaviour with MoveSpeed and JumpForce fields.

Step 2 — Enter Play Mode and tweak values

  1. Press the Unity Play button (or Ctrl+P / Cmd+P).
  2. Select Modify Me (Cube) in the Hierarchy:
    • Move its Position to a new location in the Scene view.
    • Rotate its Rotation by 45 degrees.
    • In its BoxCollider component, change Size from (1, 1, 1) to (2, 1.5, 3).
  3. Select Sample Character:
    • Change Move Speed from 5.0 to 14.5.
    • Change Jump Force from 7.0 to 12.0.

Step 3 — Exit Play Mode and review the staging window

  1. Press Stop to exit Play Mode.
  2. The Quick Restore Window pops up automatically.
  3. Inspect the organized change tree:
    • Color-coded transitions show WAS (original) → NOW (runtime tweak).
    • Filter by category: All, Transforms, Scripts, Components.
    • Check or uncheck specific properties to choose exactly what persists.
No window appeared? The Quick Restore Window only triggers when active serialized changes were detected during playback. See the Support page for what to check.

Step 4 — Commit to the Edit Mode scene, with Undo

  1. Click Apply Selected Changes (or Restore All Safe).
  2. Your runtime position, collider, and script tweaks are now permanently saved into your active Edit Mode scene.
  3. Press Ctrl+Z / Cmd+Z at any time: PlaySync Pro registers every change with Unity's native Undo system, so a commit can always be reverted.

Tips for daily usage

  • Testing multiple configurations before deciding? Click Save as Preset to store the changes in your Preset Vault and compare them later with one click.
  • Want real-time diffs during gameplay? Keep the PlaySync Studio window (Ctrl+Alt+S / Cmd+Option+S) docked next to your Game view.
  • All tools live in one place: Tools > ByteLura > PlaySync — Studio, Quick Restore Window, Preset Vault, Flight Recorder, Auto-Save Settings, and the Welcome & Hub.
