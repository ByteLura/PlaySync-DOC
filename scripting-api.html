Scripting API & Attributes

Two integration surfaces: the [AutoSavePlayMode] attribute for your runtime scripts, and the PlaySyncSession editor API for custom editor tooling.

1. The [AutoSavePlayMode] attribute

Decorating a custom MonoBehaviour class — or individual fields — with [AutoSavePlayMode] instructs PlaySync Pro to automatically persist those variables on Play Mode exit, with no staging step. Namespace:

using ByteLura.PlaySync;

Example A — class-level auto-save (all fields persist)

[AutoSavePlayMode]
public class CharacterStats : MonoBehaviour
{
    public float maxHealth = 100f;
    public float moveSpeed = 12.5f;
}

Example B — field-level auto-save (selective fields persist)

public class WeaponGun : MonoBehaviour
{
    [AutoSavePlayMode]
    public float fireRate = 0.12f;

    [AutoSavePlayMode]
    public Vector3 muzzleOffset = new Vector3(0f, 0.2f, 0.8f);

    // This field will NOT auto-save (handled via the staging window):
    public int currentAmmo = 30;
}

Fields without the attribute are not lost — they go through the normal review-and-commit flow in the Quick Restore Window and Studio.

2. Editor scripting API

Integrate PlaySync Pro directly into custom editor workflows and build scripts:

#if UNITY_EDITOR
using ByteLura.PlaySync.Editor;
#endif
// 1. Get the total number of pending staged changes:
int pendingCount = PlaySyncSession.GetPendingChangeCount();

// 2. Commit all safe staged changes with Undo support:
PlaySyncSession.RestoreAllSafe();

// 3. Discard all currently staged changes:
PlaySyncSession.DiscardAll();

// 4. Save the current staged state as a ScriptableObject preset:
PlaySyncPreset newPreset = PlaySyncSession.SaveCurrentAsPreset(
    "Combat_Tuning_V1",
    "Increased fire rate and reduced recoil.");

3. Lifecycle event hooks

Subscribe to session events in custom editor scripts:

#if UNITY_EDITOR
using UnityEditor;
using UnityEngine;
using ByteLura.PlaySync.Editor;

[InitializeOnLoad]
public static class CustomPlaySyncHooks
{
    static CustomPlaySyncHooks()
    {
        PlaySyncSession.OnChangesDetected += (count) => {
            Debug.Log("[PlaySync] Captured " + count + " changes on Play Mode exit.");
        };

        PlaySyncSession.OnChangesCommitted += (count) => {
            Debug.Log("[PlaySync] Successfully committed " + count + " properties to scene.");
        };
    }
}
#endif
