Workflows & Pro Tips

Production workflows from the product's own guides: balancing, level staging, large-project tuning, prefab overrides, and the Undo safety net.

1. Game balancing & A/B testing

Game balancing is an iterative process. Test gameplay feel live, save multiple profiles, and switch between them instantly:

  1. Enter Play Mode and test your character or weapon feel.
  2. Tweak movement speed, jump height, and recoil sliders in the Inspector.
  3. When you reach a configuration you like, click Save as Preset in the HUD.
  4. Name your preset (for example, "Player_Arcade_Fast").
  5. Repeat for an alternate configuration (for example, "Player_Simulation_Heavy").
  6. In Edit Mode, open the Preset Vault (Ctrl+Alt+P / Cmd+Option+P) and switch between profiles with one click — compare gameplay feel without duplicate scenes.

2. Level design & lighting staging

Level designers and lighting artists can position props and align colliders live:

  1. Walk your player character through the scene in Play Mode.
  2. If a platform is too far or a doorway too narrow, grab the object in the Scene view and move or scale it live.
  3. Tweak PointLight and SpotLight intensities and ranges while walking through dark areas.
  4. Add UnityEngine.Light to your Auto-Save Rule Matrix so light tweaks persist instantly on exit, without prompting.

3. Large projects — keep tracking overhead at zero

On large-scale projects with hundreds of complex runtime MonoBehaviours, character rigs, or behaviour-tree nodes:

  1. Open Tools > ByteLura > PlaySync > PlaySync Studio > Settings (or Edit > Preferences > PlaySync).
  2. Set Tracking Scope to Active Selection Only.
  3. PlaySync then exclusively monitors the specific GameObjects you select in the Hierarchy — documented as 0.00 ms idle overhead during intense gameplay profiling.

Two further scopes exist since release 1.0.1: All Scene Objects and Marked Attributes Only. Live background polling in Play Mode is opt-in and off by default, so gameplay testing carries no polling cost unless you turn it on.

4. Prefab instance overrides

  • When you tweak a prefab instance in Play Mode, PlaySync Pro tracks the instance overrides.
  • Restoring writes directly to the scene instance without breaking the root prefab link.
  • Use the standard Unity Inspector controls to apply overrides to the source asset if you want them there — PlaySync restores to the instance; pushing to the prefab asset stays a normal Unity action.

5. Safety — 100% native Undo

  • Every restore operation calls Undo.RecordObject() before writing values.
  • If you ever commit a batch of changes by mistake, press Ctrl+Z / Cmd+Z in the Unity Editor to revert all objects back to their pre-restore state.
The pattern to build on Tweak live → review the WAS vs NOW diff → commit only what you meant → keep the rest out. Presets and the Flight Recorder mean an experiment is never a one-way door.
